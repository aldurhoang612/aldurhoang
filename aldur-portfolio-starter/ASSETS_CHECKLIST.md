# Assets Checklist — Chuẩn bị hình ảnh & video trước khi Deploy

Để trang web trên **GitHub Pages (`aldurhoang612.github.io`)** tải siêu nhanh và không vượt quá giới hạn dung lượng của GitHub:
- **Ảnh tĩnh:** Xuất định dạng `.webp` hoặc `.jpg` (chiều ngang tối đa `1600px–1920px`, dung lượng mỗi ảnh dưới `400KB`).
- **Video dài / Showreel / Stage Visual:** Upload lên **YouTube (Unlisted/Public)** hoặc **Vimeo**, sau đó dán link vào trường `"videoUrl"` trong file `data/projects.json`. **KHÔNG đẩy file `.mov` / `.mp4` nặng lên GitHub.**
- **CV PDF:** Đặt file CV mới nhất tại `assets/cv/Aldur-Hoang-CV-2026.pdf`.
